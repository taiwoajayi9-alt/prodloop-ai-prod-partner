## How it fits the room

- Workshops are done in mixed-function groups. One laptop per group runs the partner; the group decides, the partner records and challenges.
- Each command reads earlier outputs, so groups should keep the same workspace across both days.
- `/challenge-me` is useful in the readout: run it on a group's document and read out the first challenge.

## Before Day 1

- Send the folder with joining instructions and ask everyone to run `/partner-setup`.
- Fill in `context/case-study.md` once the case study is agreed, and resend that file.
- Check the skills load in the version of the tool your participants use. This pack uses `.agents/skills/` and `AGENTS.md`; older versions read `.agent/skills/`.

## If something goes wrong

- A command is missing: reopen the workspace, or copy the skill folders to the global skills folder (`~/.gemini/config/skills/`).
- The partner gives generic answers: check `context/about-me.md` is filled in. More context, not more prompting.
- A group pastes real client data: stop, delete the file, and remind the room of the rule.
