# Using the partner in the Claude app or ChatGPT

The chat apps cannot read this folder directly, so you set the partner up as a project. It takes about five minutes.

## Claude (claude.ai or the Claude desktop app)
1. Create a new **Project** called "Prodloop AI Prod Partner".
2. Paste the whole of `project-instructions.md` into the project's instructions.
3. Add `prodloop-partner-knowledge.md` to the project's files.
4. Start a chat in the project and type `/partner-setup`. Add the about-me.md it gives you to the project's files.

## ChatGPT
Use a **Project**, or a **custom GPT** if you want to share the partner with others in your workspace.
1. Project: create a project, paste `project-instructions.md` into its instructions, and upload `prodloop-partner-knowledge.md` to its files.
   Custom GPT: paste `project-instructions.md` into Instructions and upload `prodloop-partner-knowledge.md` under Knowledge.
2. Start a chat and type `/partner-setup`. Add the about-me.md it gives you to the project's files.

In both apps, type a command such as `/honest-map` to start an exercise. When it finishes, save the output it gives you and add it to the project's files so later commands can build on it.

If you use Claude Code, Codex or Antigravity instead, you do not need this folder: open the repository itself.
